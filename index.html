OBS Studio Transparent Background Setup Guide

To display this chart as a transparent overlay in OBS Studio using a Browser Source, follow these steps:

  1. In OBS Studio, add a new source by selecting Sources -> Add (+) -> Browser.
  2. Check Local file if you are running this HTML file locally, or paste the URL if hosted on a web server.
  3. In the Custom CSS section of the Browser Source properties, replace all default CSS with:
body { 
  background-color: rgba(0, 0, 0, 0) !important; 
  margin: 0px auto; 
  overflow: hidden; 
}

Additional Notes:

  • Hide or remove the UI controls (.controls) and guide (.obs-guide-wrapper) when streaming by adding display: none; in CSS.
  • Apache ECharts renders with a transparent background by default when no backgroundColor option is set.
